Style guide: colour and typography

The colours and type styles the prototype uses. Every screen follows this guide; a new colour, size or weight is added here and in the theme first, never in a single screen. Every value comes from the IBMS Figma design system, through the app theme. In screens, use the token names (for example primary.main), never raw hex codes.

Colour rules

  • Every primary action is a filled Forest Green button (#008F40). Destructive confirmations (block, deactivate, reject) use Error.
  • Never use Warning Dark for text. #E8980E is unreadable on a tint; use Warning Text #945700.
  • In dark mode, words on a tint use the palette's Light shade instead of Text.
  • Hover, selected, borders and dividers are see-through tints of Grey 800 (light mode) or Grey 500 (dark mode), at 8–48%.
  • Charts: don't use Primary Light (#ADFFD3) for a series; it disappears on white. Use Primary Dark.
  • There is no separate secondary palette. Sky Blue fills that role.

Typography rules

  • Page titles are h4; card titles are h6. Body text in tables and forms is body2.
  • Plates, manifest IDs and references use the monospace token (typography.monospace: SF Mono, Menlo or Consolas, by platform) at a size from the scale, for example WB-19-C-0812.
  • Weights are 400 to 700 only. Nothing uses 800.
  • Two recorded exceptions: collapsed side-nav labels and badges are 10px, because caption (12px) clips under the icons in the 88px rail; the live scale reading on the Weighbridge grows from 32px to 56px with its column, and KPI card values are h3 that shrinks with the card down to 16px.
  • Buttons are never uppercase. Large buttons use a 16px label; Medium and Small use 14px.
  • Money is written as BDT 1,234.56. Don't use the ৳ sign: Public Sans doesn't include it, so it renders in a fallback font.
  • Table header cells are 14px SemiBold in secondary text on the neutral background.
